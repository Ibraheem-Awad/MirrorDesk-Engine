# MirrorDesk-Engine

AirPlay screen mirroring receiver engine for **MirrorDesk**, based on the open-source [UxPlay](https://github.com/FDH2/UxPlay) project and distributed under the **GNU General Public License v3.0 (GPLv3)**.

## Overview
This repository contains the C++ AirPlay receiver core and renderers utilized by MirrorDesk on macOS, including custom modifications for:
- Enhanced rotation handling and portrait/landscape state transitions
- Freeze mitigation and connection stability
- Multi-device simultaneous streaming support
- Hardware-accelerated rendering optimizations for macOS
